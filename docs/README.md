# 문서 인덱스

이 파일은 `docs` 폴더의 전체 문서 역할을 설명한다.

새 대화에서 문서 구조를 빠르게 파악해야 할 때 이 파일을 먼저 읽는다.

## 문서 역할

- `portfolio-notes.md`
  - 포트폴리오 전체 방향, 핵심 메시지, 넣을 주제를 정리한다.
  - 아직 확정되지 않은 생각도 이곳에 적는다.

- `ai-development-playbook.md`
  - 포트폴리오에 들어갈 수 있는 AI 활용 글 초안이다.
  - 외부에 보여줄 문장 톤으로 다듬는다.

- `project-stories.md`
  - 포트폴리오에 넣을 실제 프로젝트 사례를 정리한다.
  - 문제, 판단, 개선, 결과, 보여줄 역량을 사례별로 적는다.

- `personal-tech-wiki.md`
  - 프로젝트 진행 중 바로 보는 핵심 기술 위키다.
  - 긴 설명보다 체크리스트, 구조 요약, AI 지시 프롬프트를 적는다.
  - 한눈에 들어와야 하므로 사족을 줄인다.

- `development-playbook.md`
  - 개인 기술 위키보다 긴 개발 플레이북이다.
  - 배경, 회고, 실패 과정, 왜 그런 판단을 했는지 자세히 적는다.
  - 개인 기술 위키에 넣기에는 긴 내용을 이곳에 둔다.

## 작성 기준

- 전체 방향이나 아이디어는 `portfolio-notes.md`에 적는다.
- 외부에 보여줄 글 초안은 `ai-development-playbook.md`에 적는다.
- 실제 프로젝트 경험은 `project-stories.md`에 적는다.
- 프로젝트 중 바로 쓸 핵심 규칙은 `personal-tech-wiki.md`에 적는다.
- 긴 설명과 회고는 `development-playbook.md`에 적는다.

## 새 대화에서 읽는 순서

1. 문서 구조를 파악하려면 `README.md`
2. 포트폴리오 방향을 잡으려면 `portfolio-notes.md`
3. 기술 규칙을 바로 쓰려면 `personal-tech-wiki.md`
4. 사례의 배경까지 보려면 `development-playbook.md`
5. 포트폴리오 사례 문장을 만들려면 `project-stories.md`
